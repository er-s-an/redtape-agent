# RedTape

**An autonomous agent that watches the dependency chain of your cross-border documents — passport, visa, permit, license — and quietly handles renewals end to end, surfacing only when a real decision needs you.**

Built with the [Strands Agents SDK](https://strandsagents.com/) for the **Agents for Humans Hackathon** (Everyday Agents track).

> Status: under active construction. See `docs/concept.md` for the product definition and `docs/build-plan.md` for the execution plan.

## Why

For people who live across borders, life admin is a dependency graph, not a reminder list: a driver's-license renewal needs a valid passport and lawful status; a visa stamp needs 6+ months of passport validity; one missed window cascades into lost status or missed travel. RedTape computes deadlines *backwards* from those constraints, pre-fills the real forms, books the appointments, and only interrupts you when a decision is genuinely yours.
